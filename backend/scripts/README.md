# ابزارهای اسکریپت پروژه Journey Hub

این دایرکتوری شامل اسکریپت‌های مفید برای توسعه، تست و نگهداری پروژه Journey Hub است.

## ابزارهای امنیتی

### بررسی آسیب‌پذیری‌ها با govulncheck

اسکریپت `govulncheck.sh` برای بررسی آسیب‌پذیری‌های وابستگی‌های Go استفاده می‌شود. این ابزار با استفاده از پایگاه داده آسیب‌پذیری‌های Go، وابستگی‌های پروژه را بررسی می‌کند و موارد امنیتی را گزارش می‌دهد.

#### استفاده

```bash
# اجرای مستقیم
./scripts/govulncheck.sh

# نتایج با فرمت JSON
govulncheck -json ./... > vulnerability-report.json
```

#### نحوه عملکرد

1. اگر ابزار govulncheck از قبل نصب نشده باشد، آن را نصب می‌کند
2. تمام کد پروژه را برای آسیب‌پذیری‌های شناخته‌شده اسکن می‌کند
3. در صورت یافتن موارد، جزئیات را نمایش می‌دهد

#### ادغام با CI/CD

این ابزار در چند مکانیزم خودکار ادغام شده است:
- هوک pre-commit برای بررسی آسیب‌پذیری‌ها قبل از هر commit
- GitHub Action برای اجرای منظم در مخزن و pull requestها

#### معیارهای بررسی

govulncheck آسیب‌پذیری‌ها را براساس پایگاه داده آسیب‌پذیری Go بررسی می‌کند:
- https://pkg.go.dev/golang.org/x/vuln

#### چگونگی رفع آسیب‌پذیری‌ها

در صورت شناسایی آسیب‌پذیری:
1. وابستگی مشکل‌دار را به نسخه امن تر بروزرسانی کنید
2. اگر امکان بروزرسانی نیست، از الگوهای امن‌تر برای استفاده از کتابخانه بهره بگیرید
3. در مواردی که امکان رفع سریع وجود ندارد، ریسک را مستند کرده و برای آن برنامه‌ریزی کنید

## هوک‌های git

دایرکتوری `hooks/` شامل هوک‌های git برای کنترل کیفیت کد و استانداردهای پروژه است. برای نصب این هوک‌ها از اسکریپت `install-hooks.sh` استفاده کنید.
