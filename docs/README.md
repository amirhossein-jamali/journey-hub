# Journey Hub Project Documentation

This folder contains various documentation for the Journey Hub project to assist developers.

## Documentation Index

- [Contributing Guide](CONTRIBUTING.md) - Comprehensive guide for new developers
- [Code Style Guide](CODE_STYLE.md) - Code writing rules and standards
- [Project Architecture](ARCHITECTURE.md) - Complete explanation of the project's hexagonal architecture
- [API Standards](API_STANDARDS.md) - API design and documentation standards

## Introduction

Journey Hub is an online platform for travel planning and management that allows users to plan their trips online, gather information about travel destinations, and share their travel experiences with others.

## How to Use the Documentation

1. First, read the [Project Architecture](ARCHITECTURE.md) to understand the overall architecture and structure of the project.
2. Then, read the [Contributing Guide](CONTRIBUTING.md) to understand the development workflow and contribution rules.
3. Before starting to code, review the [Code Style Guide](CODE_STYLE.md).
4. If you're working on the API, be sure to read the [API Standards](API_STANDARDS.md).

## Documentation Updates

All developers are requested to update the documentation when making project changes that require documentation updates by creating a pull request.
